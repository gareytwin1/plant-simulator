How to use this plan during development

This is your master checklist for tasks, milestones, and integration points. Reference it constantly while implementing.

Task ID naming: Each task has an ID like T0-1, T1-2, etc. Reference these in commit messages, PR descriptions, and branch names so progress is traceable.

Branch naming: Always match the recommended branch name. Example: feature/pid-block, refactor/equipment-contract.

Status tracking: The live artifact maintains shared status. Update it as work progresses so other agents know what's complete.

Quick reference: spine vs. satellites

Spine (Sequential) Core files that rewrites are one owner at a time: equipment base, engine, topology, solver. One agent, strict left-to-right.
Satellites (Parallel) New modules in their own directories, depending only on frozen contracts. Can be developed and merged independently.

Working with dependencies

Every task lists its dependencies. A task is "ready" when all its dependencies are complete ("done" status).

If a task is blocked on a dependency:

  • The task's "Blocked" status is visible in the live artifact.
  • Dependency chips in the task details turn green as blockers clear.
  • Use the note field to record why it's blocked (e.g., "waiting on T4-1 to merge").

Rebase strategy: After each checkpoint merges to main, satellite branches rebase onto main. Do not merge main backwards into the spine.

File ownership rules

  • app/equipment/base.py, app/engine/, app/plant/topology.py — spine-owned. Satellites cannot touch these.
  • app/main.py — highest-conflict file. One branch at a time; release it immediately after merging.
  • app/config.py — append-only, one section per module. Never reorder.
  • config/plants/olefins_lite.yaml — shared config. Own only your milestone's top-level key (nodes, equipment, limits, controllers, interlocks).
  • static/compressor.js — frozen, dies at M16. Do not invest in it.

Updating the live artifact

The status dropdowns in the live build plan save to a shared database. When you finish a task:

  1. Open the live artifact.
  2. Find your task and expand it.
  3. Change the status dropdown to "Complete".
  4. Milestone status recalculates automatically.

The note field is for owner attribution, branch state, or "why blocked" so information doesn't live in someone's head.
